# Framing

Grammar can fundamentally shift the way we perceive the information presented to us.

<div style={{ display: 'flex', gap: '0.5rem', marginBottom: '1rem' }}>
    <Button>
        Save $20 a year
    </Button>
    <Button>
        Don’t lose $20 a year
    </Button>
</div>

Which looks more appealing?
