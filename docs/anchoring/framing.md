# Framing

Grammar can fundamentally shift the way we perceive the information presented to us.

<p style={{ fontSize: "1.5rem", fontWeight: "bold" }}>“Save $20 a year”</p>
<p style={{ fontSize: "1.5rem", fontWeight: "bold" }}>“Don’t lose $20 a year”</p>

Which looks more appealing?
