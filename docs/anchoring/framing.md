# Framing

Grammar can fundamentally shift the way we perceive the information presented to us.

<div style={{ display: "flex", gap: "0.5rem" }}>
    <Button variant="confirmSafe" style={{ width: "300px", display: "flex", alignItems: "center" }}>
        <p style={{ fontSize: "1.5rem", fontWeight: "bold", color: "var(--dnid-neutral-0)" }}>“Save $20 a year”</p>
    </Button>
    <Button variant="confirmDanger" style={{ width: "300px" }}>
        <p style={{ fontSize: "1.5rem", fontWeight: "bold", color: "var(--dnid-neutral-0)" }}>“Don’t lose $20 a year”</p>
    </Button>
</div>

Which looks more appealing?
