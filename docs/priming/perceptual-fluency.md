# Perceptual Fluency

Perceptual fluency describes the concept that users will trust a UI more if it is easier to process.

For example, a submission form with a long loading screen will be perceived as trustworthy, whereas a submission form that instantly loads will be seen as "broken", even if the system's internal processing time is the same. This is especially true if the action being completed is sensitive, like entering financial information.
