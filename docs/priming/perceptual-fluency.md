# Perceptual Fluency

<PerceptualFluencyDemo />

Perceptual fluency describes the concept that users will trust a UI more if it is easier to process.

For example, a submission form with a long loading screen will be perceived as trustworthy, whereas a submission form that instantly loads will be seen as "broken", even if the system's internal processing time is the same.

This is especially true in financial transactions, where users are concerned about the security of their data. A loading time that feels "too quick" can be percieved as a bug in the system or a sign of the site they're on being compromised.

Try toggling between the "Instant" and "2-sec delay" modes. How does it feel to check out? I'm willing to bet that the longer loading time feels better. While most people think they prefer fast loading times, in practice, it is highly context-dependent.
