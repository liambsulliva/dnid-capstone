# Variable Reinforcement

<FeedbackLoopDemo variant="variableReinforcement" />

Variable reinforcement builds on the concept of [feedback loops](./feedback-loop.md) by introducing variability to the rewarding action. It's a powerful tool to keep users engaged and motivated.
