# The Invisible Hand of UX

The Invisible Hand of UX is a Docusaurus site that tallies persuasive and manipulative interface patterns and explains them through short blurbs, relevant images, and interactive demos. It organizes examples categorically so readers can quickly understand how specific UX choices influence attention, behavior, decision-making, and autonomy.

## At a Glance

- TypeScript + React + Docusaurus documentation site
- Glossary-style content with interactive component demos embedded via MDX
- Five category-based sidebars with autogenerated navigation
- CSS Modules + custom design tokens with light/dark mode support
- CSS-only animations with `prefers-reduced-motion` accessibility support
- Built and deployed through GitHub Actions

## Main Categories

- [Anchoring](https://uxwiki.liambsullivan.com/docs/anchoring/introduction)

## High-Level Structure

- `docs/` — Markdown/MDX content organized by category (`anchoring/`, `attention/`, `behavior/`, `coercion/`, `priming/`). Each subfolder has a `_category_.json` for sidebar metadata.
- `src/components/Demos/` — Self-contained interactive demo components, each with a co-located `styles.module.css`
- `src/components/General/` — Shared UI primitives: `Button`, `WindowContainer`, `WindowChrome`, `PriceLadder`, and `PatternGrid` (with inline SVG category graphics)
- `src/pages/` — Custom pages: `index.tsx` (hero + pattern grid), `about.tsx`, `attribution.tsx`
- `src/theme/` — Swizzled Docusaurus components (e.g. `ColorModeToggle`)
- `src/css/custom.css` — Global design tokens (`--dnid-*` CSS variables), Infima overrides, and keyframe animations
- `static/` — Static assets (icons, banner images, manifest)
- `docusaurus.config.ts` — Site metadata, navbar, preset config, Sora font injection, theme settings
- `sidebars.ts` — Five autogenerated sidebar definitions, one per category folder

## Navigation

The top navbar exposes five sections — Anchoring, Attention, Behavior, Coercion, and Priming — each linked to its own autogenerated sidebar. Sidebars are derived from the folder structure under `docs/`, so adding a new Markdown file to a category folder automatically inserts it into the corresponding sidebar.

The homepage renders multiple carousels of animated cards that deep-link into the docs. Footer quick links mirror the navbar categories, and secondary footer links point to `/about` and `/attribution`.

## Styling

- **CSS Modules** — Each component and page has a co-located `styles.module.css` for scoped styles
- **Design tokens** — `src/css/custom.css` defines `--dnid-*` custom properties that override Docusaurus's Infima framework variables; separate light and dark token sets are declared under `[data-theme='dark']`
- **Typography** — [Sora](https://fonts.google.com/specimen/Sora) (Google Fonts) injected via `headTags` in `docusaurus.config.ts`
- **Class merging** — `clsx` is used throughout components for conditional class composition as needed

## Animations

All animations are CSS-exclusive. No Framer Motion, GSAP, or other animation libraries are used in this project.

- **Keyframes** — Defined in `src/css/custom.css` (e.g. `logo-recoil`) and in component-level `styles.module.css` files
- **SVG micro-interactions** — `PatternGrid` category graphics embed `<style>` blocks with hover/active animations (scale, opacity, shake, pulse, clock hands)
- **JS-timed sequencing** — `setTimeout` drives modal appearances, badge dismissals, and staged UI transitions (e.g. `NaggingModal`, `ObstructionDemo`, `FalseUrgencyDemo`)
- **Accessibility** — Components respect `prefers-reduced-motion: reduce` where motion could be disorienting

## Development

### To Run Locally

- Install dependencies:
  - `npm install`
- Start local dev server:
  - `npm start`
- Build production bundle:
  - `npm run build`
- Serve built output locally:
  - `npm run serve`
- Type-check TypeScript:
  - `npm run typecheck`
